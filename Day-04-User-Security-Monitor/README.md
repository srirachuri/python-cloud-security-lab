# Day 4: User Security Monitor

## 📌 Objective

Develop a Python-based User Security Monitor that collects user login information, checks whether an IP address is blocked, evaluates failed login attempts, and generates a simple security report.

This project simulates basic user authentication monitoring commonly used in cybersecurity and cloud security environments.

---

## 🛠 Technologies Used

- Python 3
- Ubuntu Linux
- Oracle VirtualBox
- Nano Text Editor
- Linux Terminal
- Python Virtual Environment (venv)

---

## 📚 Concepts Learned

- Variables
- Lists
- User Input (`input()`)
- Integer Conversion (`int()`)
- Membership Operator (`in`)
- Conditional Statements (`if`, `else`)
- Security Report Generation
- Python Virtual Environment

---

## ⚡ Commands Used

### Activate Virtual Environment

```
source venv/bin/activate
```

### Create/Edit Python Script

```
nano user_monitor.py
```

### Run the Program

```
python3 user_monitor.py
```

---

## ⚡ Program Features

- Accepts a username.
- Accepts an IP address.
- Accepts failed login attempts.
- Stores blocked IP addresses in a list.
- Checks whether the entered IP is blocked.
- Detects suspicious login activity.
- Displays a formatted security report.
